# Statistics - The Organic Chemistry Tutor

Hi, this is the repo about my statistics learning from <https://www.video-tutor.net/statistic.html>.

Each lesson on the site has its own Markdown note, named `chapter-lesson-title.md`. The notes are written in my own words. They cover the concepts, formulas and worked examples from each video, with every calculation re-checked. Where a video contains a slip, the note says so and gives the corrected value. Each note links to its original video.

The videos and the website belong to The Organic Chemistry Tutor. These notes are a personal study companion and are not affiliated with or endorsed by the channel.
