1Introduction to statistics

Population vs sample 1.2 · 1.4

sizemeanSDvar.prop.
population → parameter$N$$\mu$$\sigma$$\sigma^2$$p$
sample → statistic$n$$\bar x$$s$$s^2$$\hat p$

We compute statistics ($\bar x, s, \hat p$) to estimate unknown parameters ($\mu, \sigma, p$). Bigger samples → more precise inferences.

Types of data & scales of measurement 1.3 · 1.5 · 6.5

  • Quantitative (numbers): discrete = counted, whole values · continuous = measured, any value in a range.
  • Qualitative (categories, words): colors, tastes, opinions.

Ratios like "twice as much" only make sense on a ratio scale (true zero): 20 kg is twice 10 kg, but 20 °C is not twice as hot as 10 °C.

Dot plots, line plots, stem-and-leaf 2.4 – 2.7

  • Height of a column = frequency; mode = tallest column; total amount $= \sum(\text{value}\times\text{frequency})$.
  • "at least $k$" = $x \ge k$, "at most $k$" = $x \le k$ — both include $k$.

Histogram & frequency polygon 2.8 · 2.9

Equal-width classes. Histogram bars touch (bar-graph bars don't). For the polygon, add a point with $f = 0$ one class width beyond each end. Long right tail → skewed right.

5Probability

Basic probability & complements 5.1 · 5.3 · 5.8

$P(A) = \dfrac{n(A)}{n(S)} = \dfrac{\text{favorable}}{\text{total}}, \qquad 0 \le P(A) \le 1$
$P(A') = 1 - P(A)$

$n$ fair coin flips in one given order: $(1/2)^n$. "In any order" → count every arrangement that works.

Addition rule — "or" 5.2 · 5.6 · 5.7

$P(A \cup B) = P(A) + P(B) - P(A \cap B)$
mutually exclusive: $P(A \cup B) = P(A) + P(B)$

or → $\cup$ → add (minus the overlap). A probability above 1 means an overlap was counted twice.

Conditional probability & multiplication — "and" 5.4 · 5.5 · 5.7 · 5.8

conditional$P(A \mid B) = \dfrac{P(A \cap B)}{P(B)} = \dfrac{n(A \cap B)}{n(B)}$
multiplication$P(A \cap B) = P(A \mid B)\,P(B) = P(B \mid A)\,P(A)$
independent$P(A \cap B) = P(A)\,P(B)$   (with replacement)
chain (dependent)$P(A_1 \cap B_2 \cap C_3) = P(A_1)\,P(B_2 \mid A_1)\,P(C_3 \mid A_1 \cap B_2)$

Independent ≠ mutually exclusive. Independent: one doesn't affect the other. Mutually exclusive: can't both happen, $P(A\cap B) = 0$. Without replacement → update counts and total.

Tree diagrams & Bayes' theorem 5.10 · 5.11

$P(A \mid B) = \dfrac{P(B \mid A)\,P(A)}{P(B)}$
$P(B) = P(B \mid A)\,P(A) + P(B \mid A')\,P(A')$   (add the branches that end in $B$)

Rare condition (1%) + 10% false positives → only ~9% of positive tests are real. Check with counts (e.g. 10,000 people).

Expected value 5.9

$E(X) = \sum x\,P(x) = x_1p_1 + x_2p_2 + \dots + x_np_n$

Total expected over $n$ trials $= n\,E(X)$. Losses go in as negative values; the $p$'s add to 1. $E(X)$ is a long-run average — no single game pays exactly 1.25.

6Discrete probability distributions

Binomial — $x$ successes in $n$ trials 6.1 · 6.2

$P(X = x) = {}_nC_x\, p^x q^{\,n-x}, \qquad {}_nC_x = \dfrac{n!}{(n-x)!\,x!}, \qquad q = 1 - p$
$\mu = np, \qquad \sigma = \sqrt{npq}$

Fixed $n$, success/failure, independent trials, same $p$. "Exactly" → one term; "at most / at least / fewer than" → add terms (remember $x = 0$).

Geometric — waiting for the first success 6.1 · 6.3

on trial $x$by trial $x$before $x$after $x$$x$ or later
$q^{x-1}p$$1 - q^x$$1 - q^{x-1}$$q^x$$q^{x-1}$

$\mu = \dfrac1p, \qquad \sigma^2 = \dfrac{1-p}{p^2}, \qquad \sigma = \dfrac{\sqrt{1-p}}{p}$

Poisson — events in an interval 6.1 · 6.4

$P(X = x) = \dfrac{\mu^x e^{-\mu}}{x!}, \qquad \dfrac{\mu_2}{\mu_1} = \dfrac{t_2}{t_1}, \qquad \text{mean} = \sigma^2 = \mu,\;\; \sigma = \sqrt\mu$

Adjust $\mu$ first whenever the question's interval differs from the given rate. "More than $k$" → $1 - P(X \le k)$.

Discrete vs continuous 6.5

Discrete (ch. 6): binomial, geometric, Poisson — probabilities sit on single values. Continuous (ch. 7–8): uniform, exponential, normal — probability is area. Rounding turns continuous data into discrete data.

8Normal distribution, CLT and standard error

z-scores & normal probabilities 8.1 · 8.2

$z = \dfrac{x - \mu}{\sigma}, \qquad x = \mu + z\sigma, \qquad f(x) = \dfrac{1}{\sigma\sqrt{2\pi}}\, e^{-\frac12\left(\frac{x-\mu}{\sigma}\right)^2}$

z-table = left area. Right = 1 − left; between = difference of two lefts. Percentile: area → $z$ → $x$. Count = probability × group size.

Empirical rule (68 – 95 – 99.7) 8.1 · 8.2

Normal data only. Precise values: 68.27 / 95.45 / 99.73 %, per region 34.13 / 13.59 / 2.14 / 0.135 %. For any shape use Chebyshev (9.6).

Sampling distributions: LLN, CLT, standard error 8.3 · 8.4 · 8.5

question about…distributionz
one value $x$$X \sim N(\mu, \sigma)$$\dfrac{x - \mu}{\sigma}$
mean of $n$ values$\bar X \sim N\!\left(\mu, \frac{\sigma}{\sqrt n}\right)$$\dfrac{\bar x - \mu}{\sigma/\sqrt n}$
sum of $n$ values$\sum X \sim N(n\mu, \sqrt n\,\sigma)$$\dfrac{\sum x - n\mu}{\sqrt n\,\sigma}$
standard error$\sigma_{\bar x} = \dfrac{\sigma}{\sqrt n}$ (population $\sigma$)$\text{SE} = \dfrac{s}{\sqrt n}$ (sample $s$)

SD = spread of individual values; SE = spread of sample means. SE ∝ $1/\sqrt n$. The LLN says nothing about a single trial — the next flip is still 50/50.

9Confidence intervals

CI for a mean, $\sigma$ known (z) 9.1 · 9.2

$\bar x - z\dfrac{\sigma}{\sqrt n} \lt \mu \lt \bar x + z\dfrac{\sigma}{\sqrt n}, \qquad \text{EBM} = z\dfrac{\sigma}{\sqrt n}$
look up $z$ from the left area $\dfrac{1 + \text{CL}}{2}$

Higher confidence → bigger $z$ → wider. Bigger $n$ → narrower. $\alpha = 1 - \text{CL}$, split $\alpha/2$ per tail.

CI for a mean, $\sigma$ unknown (t) 9.3

$\bar x \pm t_{\nu,\,\alpha/2}\,\dfrac{s}{\sqrt n}, \qquad \nu = n - 1, \qquad \dfrac{\alpha}{2} = \dfrac{1 - \text{CL}}{2}$

Use $t$ when only $s$ is known, especially $n \lt 30$. t-table: row $\nu$, column = one-tail area $\alpha/2$. As $\nu$ grows, $t \to z$.

CI for a proportion 9.4

estimate$\hat p = \dfrac{x}{n}, \;\; \hat q = 1 - \hat p$check$n\hat p\hat q \ge 10$
margin of error$E = z\sqrt{\dfrac{\hat p\,\hat q}{n}}$interval$\hat p - E \lt p \lt \hat p + E$

Given an interval: $\hat p$ = its midpoint, $E$ = half its width. The square-root part is the standard error of $\hat p$.

Sample size 9.4 · 9.5

mean: $n = \dfrac{z^2\sigma^2}{E^2}$    proportion: $n = \dfrac{z^2\,\hat p\,(1 - \hat p)}{E^2}$

Both come from solving $E = z \times \text{SE}$ for $n$. No estimate of $\hat p$? Use 0.5 (largest $n$). Always round up. Higher confidence or smaller $E$ → larger $n$; $E$ is squared, so it matters most.

Chebyshev's theorem 9.6

at least $\;1 - \dfrac{1}{k^2}\;$ of any data set lies within $k$ SDs of the mean

$k = \dfrac{x - \mu}{\sigma}, \qquad k \gt 1$

Answers are lower bounds — say "at least". $k = 2$ → 75%, $k = 3$ → 88.9%. Use the empirical rule only when the data are normal.

10Hypothesis testing — one sample

Hypotheses & tails 10.1 · 10.3

p-value method 10.6

p-value = probability, if H₀ is true, of a result at least as extreme as the one observed. p < α → reject H₀; p ≥ α → fail to reject. Always gives the same decision as the critical-value method.

Every test, 5 steps: ① write H₀/Hₐ → ② pick α, tails, critical value → ③ compute the statistic → ④ compare (or p-value vs α) → ⑤ conclude in words.

11Hypothesis testing — two samples

Difference of two means (independent) 11.1

$t\ (\text{or } z) = \dfrac{(\bar x_1 - \bar x_2) - (\mu_1 - \mu_2)}{\sqrt{\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}}}$   Welch: $\text{df} = \dfrac{\left(\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}\right)^2}{\frac{(s_1^2/n_1)^2}{n_1 - 1} + \frac{(s_2^2/n_2)^2}{n_2 - 1}}$

H₀: $\mu_1 = \mu_2$ (difference 0). Small samples → $t$ with Welch df; large → $z$. $SE_{\text{diff}} = \sqrt{SE_1^2 + SE_2^2}$: two sources of chance, so bigger than either.

Cohen's d — effect size 11.2

$d = \dfrac{|\bar x_1 - \bar x_2|}{s_p}, \qquad s_p = \sqrt{\dfrac{(n_1 - 1)s_1^2 + (n_2 - 1)s_2^2}{n_1 + n_2 - 2}}$

Equal sample sizes: $s_p = \sqrt{(s_1^2 + s_2^2)/2}$. The test asks whether there is a difference (÷ SE, shrinks with $n$); $d$ asks how big (÷ SD, doesn't). Significant ≠ big.

Two proportions 11.3

$\hat p_1 = \dfrac{x_1}{n_1},\;\; \hat p_2 = \dfrac{x_2}{n_2},\;\; \bar p = \dfrac{x_1 + x_2}{n_1 + n_2}, \qquad z = \dfrac{(\hat p_1 - \hat p_2) - 0}{\sqrt{\bar p(1 - \bar p)\left(\frac{1}{n_1} + \frac{1}{n_2}\right)}}$

Pool because H₀ says the rates are equal without saying what they equal. "Fail to reject" = no significant difference found, not "proven equal".

Matched / paired samples 11.4

$\bar x_d = \dfrac{\sum x_d}{n}, \;\; s_d = \sqrt{\dfrac{\sum (x_d - \bar x_d)^2}{n - 1}}, \;\; t = \dfrac{\bar x_d - \mu_d}{s_d/\sqrt n}, \;\; \text{CI: } \bar x_d \pm t\dfrac{s_d}{\sqrt n}$

Pairing removes person-to-person variation → smaller SE → real effects easier to detect. Match Hₐ to the claim ("reduces" → $\mu_d \lt 0$ when $d$ = after − before).

12The chi-square distribution

The chi-square distribution 12.1

$\chi^2_k = Z_1^2 + Z_2^2 + \dots + Z_k^2 \quad (Z_i \text{ independent standard normal})$

$f(x) = \dfrac{x^{k/2 - 1}\,e^{-x/2}}{2^{k/2}\,\Gamma\!\left(\frac{k}{2}\right)}, \quad x > 0 \qquad \mu = k, \quad \sigma^2 = 2k, \quad \sigma = \sqrt{2k}$

df $= 4$: $\;f(x) = \dfrac{x\,e^{-x/2}}{4}, \qquad P(\chi^2 > x) = e^{-x/2}\left(1 + \dfrac{x}{2}\right)$

$k$ = df. $\Gamma(n) = (n - 1)!$ for whole numbers, $\Gamma\!\left(\tfrac12\right) = \sqrt\pi$. Only $x > 0$ because it is a sum of squares, and it averages $k$ when H₀ is true. In practice read areas from the χ² table.

Goodness of fit 12.1

$E = n\,p, \qquad \chi^2 = \sum \dfrac{(O - E)^2}{E}, \qquad \text{df} = k - 1 \;\;(k = \text{categories})$

Always right-tailed: large $\chi^2$ → the data don't fit the claimed distribution → reject H₀.

Test of one variance / SD 12.2

$\chi^2 = \dfrac{(n - 1)\,s^2}{\sigma_0^2}, \qquad \text{df} = n - 1$

If H₀ is true, $s^2/\sigma_0^2 \approx 1$ so $\chi^2 \approx$ df. Tables list right-tail areas: for a left-tailed test look up $1 - \alpha$ and reject only if $\chi^2$ is below it.

Test of independence (contingency table) 12.3

$E = \dfrac{\text{row total} \times \text{column total}}{\text{grand total}}, \qquad \chi^2 = \displaystyle\sum_{\text{all cells}} \dfrac{(O - E)^2}{E}$

$\text{df} = (r - 1)(c - 1)$,   $r$ = rows, $c$ = columns (totals not counted)

Under independence every row has the same split as the whole table. Large $\chi^2$ → reject independence → the variables are related.

13Regression and correlation

Least-squares line 13.1

$\hat y = mx + b, \qquad m = \dfrac{n\sum xy - \sum x \sum y}{n\sum x^2 - \left(\sum x\right)^2}, \qquad b = \dfrac{\sum y - m\sum x}{n}$

Table columns $x, y, xy, x^2$ (and $y^2$ for $r$). Don't round $m$ before computing $b$. Excel: SLOPE, INTERCEPT.

Covariance 13.3

$\text{cov}(x, y) = \dfrac{\sum (x - \bar x)(y - \bar y)}{n - 1}$   (population: ÷ $N$)

The sign gives the direction; the size depends on the units. Each deviation column sums to 0 — a handy check.

Correlation coefficient $r$ 13.2 · 13.4

$r = \dfrac{\text{cov}(x, y)}{s_x\,s_y} = \dfrac{n\sum xy - \sum x\sum y}{\sqrt{\left[n\sum x^2 - (\sum x)^2\right]\left[n\sum y^2 - (\sum y)^2\right]}}$

$-1 \le r \le 1$. Sign = direction, size = strength of the linear link. $r \approx 0$ can still hide a curved relation. Example data: $r = 8.5 / (2.55 \times 3.39) \approx 0.983$. Correlation is not causation.
